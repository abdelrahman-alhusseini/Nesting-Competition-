Michael & Son Nesting Champions V14

WHAT CHANGED
- Added the approved light-theme Draw Cards page.
- Card reveal now uses a Flutter 3D flip animation on the Draw Cards design.
- Even-number cards expose Keep +1 / Gamble actions.
- Special cards expose Save Card / Use Card actions through Flutter.
- Added approved Leaderboard and Activity Feed pages with live Flutter/Supabase overlays.
- Added approved landscape How To Play page.
- Removed the standalone Rewards page from agent navigation.
- Added admin-configurable +4 and -6 gamble outcome percentages.

IMPORTANT DATABASE STEP
Your existing Supabase database needs two new game_settings columns and an updated resolve_even_card function.
Run this file in the Supabase SQL Editor:
  APPLY_GAMBLE_PERCENTAGES_IN_SUPABASE.sql

The two gamble percentages are edited from:
  Admin > Settings > Draw Engine Settings > EVEN-NUMBER GAMBLE OUTCOME
They must total 100%.
