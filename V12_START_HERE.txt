Michael & Son Nesting Champions — V12 Admin UI
================================================

WHAT CHANGED
- Keeps all six approved V11 admin artwork pages and their Flutter/Supabase overlays.
- Replaces Manual Draw with the approved light-theme card artwork.
- Manual Draw now uses the same permanent admin sidebar style as the other approved pages.
- Admin can grant a real pending draw to an active agent through Supabase.
- Admin can run unlimited non-destructive test draws without changing scores, bookings, or Supabase game data.
- Test draws use a real Flutter 3D card-flip animation with navy/gold Michael & Son styling.
- Test results and recent manual grants are real Flutter/Supabase content.
- Improved all admin dialog, input, dropdown, popup, and form colors for strong contrast and theme consistency.
- Settings percentage values now render in readable navy text on light blue/white fields.

RUN
1. Open this folder (the one containing pubspec.yaml) in VS Code.
2. Run:
   flutter clean
   flutter pub get
   flutter analyze
   flutter run -d chrome

SUPABASE
- Existing Supabase configuration is preserved.
- If using Edit Username / Change Password from Users Management, deploy the included update-user Edge Function as described in the V11 notes/deploy script.
